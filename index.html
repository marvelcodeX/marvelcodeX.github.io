RAG + Local LLM

shipped

PDF Intelligence System

A lightweight Retrieval-Augmented Generation (RAG) system that lets users query PDF documents using fully local language models.

It combines semantic search with vector embeddings and Ollama-powered inference to answer questions from the document without cloud APIs. Everything runs locally, so documents stay on your machine. It is built for lightweight models under 2GB like Phi-3, qwen2:1.5b, and tinyllama.

Integrity + Intrusion Detection

shipped

File Integrity Monitor

A desktop cybersecurity tool that watches files for unauthorized changes using SHA-256 hashing and real-time filesystem monitoring.

It stores SHA-256 baseline snapshots in SQLite and uses watchdog to detect create, modify, delete and move events instantly. Every log line is HMAC-signed, so tampering with the logs can be detected, and a dark-themed dashboard shows a colour-coded alert feed while monitoring runs in background threads.
