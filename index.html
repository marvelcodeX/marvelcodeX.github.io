    • Python
    • FastAPI
    • React
    • Ollama
    • PostgreSQL
    • AST

    • Python
    • FastAPI

    • PostgreSQL
    • Docker
    • AWS
    • NetworkX
    read more

    Built around benchmark-driven rule engines, compliance mapping, and machine learning to identify risks, prioritize findings, and visualize potential attack paths — helping teams understand cloud risks before they become incidents.

    Log Forensics Tool

    A desktop security analysis tool that detects suspicious activity across system, authentication, and web server logs through automated threat detection.

    • Python
    • CustomTkinter
    • SQLite
    • Syslog
    • Regex
    • Security
    read more

    It combines multiple detection engines, risk scoring, IP geolocation, and an interactive incident timeline to simplify forensic investigations — built as a practical tool for security analysts to investigate faster and with greater context.

    GitHub
  4. 04 shipped

    RAG + Local LLM

    PDF Intelligence System

    A lightweight Retrieval-Augmented Generation (RAG) system that lets users query PDF documents using fully local language models.

    • Python
    • Streamlit
    • FAISS
    • Ollama
    • Sentence Transformers
    • PyMuPDF
    • Gradio
    read more

    It combines semantic search with vector embeddings and Ollama-powered inference to deliver grounded answers without cloud APIs. 100% local and private — designed to run on lightweight models under 2GB like Phi-3, qwen2:1.5b, and tinyllama.

    GitHub
